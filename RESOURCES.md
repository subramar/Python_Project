# Veeva Vault EDC Study Build Resources

## Knowledge

- [Veeva Clinical Data Help: Study Design Process Overview](https://clinicaldata.veevavault.help/en/lr/study-designers/study-design-process-overview/)
  Veeva's official one-page map of the study build: definitions → schedule → rules → validate & publish. Use for: the big picture; **primary source for lesson 0001**.
- [Veeva Help: Creating Forms, Item Groups & Items](https://clinicaldata.veevavault.help/en/lr/study-designers/creating-forms/)
  Item types (EDC, Status, Header, Derived…), repeating item group display formats, reserved words, codelists and units. Use for: form-level build questions.
- [Veeva Help: Creating Event Groups & Events](https://clinicaldata.veevavault.help/en/lr/study-designers/creating-events/)
  Events = visits, Event Groups contain them, repeating Event Groups = cycles. Use for: schedule design.
- [Veeva Help: Working with Casebook Versions in Studio](https://clinicaldata.veevavault.help/en/lr/study-designers/casebook-versions/)
  Validate → publish → new version; what becomes read-only; destructive changes. Use for: amendments and change control (lesson 0004).
- [Veeva Help: Creating Rules (V2)](https://clinicaldata.veevavault.help/en/lr/study-designers/rules/)
  The expression engine: `#define`, `@` floating vs `$` fully qualified identifiers, repeating references, rule action types and processing order. Use for: lesson 0003.
- [Veeva Help: Formula Reference V2](https://cdmshelp.veeva.com/gr/resources/formula-reference/)
  The function list for rule expressions. Use for: checking rule syntax.
- [Veeva Education Services](https://education.veeva.com/)
  Official training, including the *Certified Veeva EDC Study Builder* credential (about 36 instructional hours over 5 days, plus an exam, according to [Veeva's credential pages](https://credentials.veeva.com/0014dd8a-25b0-4f0b-9a51-34122d74e3e1)). Use for: after the interview, or as a talking point ("I plan to certify").

## Wisdom (Communities)

- [Society for Clinical Data Management (SCDM)](https://scdm.org/)
  The professional body for clinical data managers and builders, with forums, webinars and an annual conference. Use for: networking and checking how teams actually run builds.
- [r/clinicalresearch](https://www.reddit.com/r/clinicalresearch/)
  Large, active subreddit that includes CDM and EDC build roles. Use for: interview experiences and job-market reality checks. Treat individual answers as anecdote.
- LinkedIn: people with the *Certified Veeva EDC Study Builder* credential. Use for: informational chats about what Vault build interviews ask.

## Gaps
- No hands-on sandbox. Veeva doesn't offer public trial vaults, so practice is simulated.
- No official Veeva "Rave → Vault" migration guide found. The Rave-side comparisons in lessons are the teacher's mapping, flagged as approximate.
