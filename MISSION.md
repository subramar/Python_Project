# Mission: Veeva Vault EDC Study Build

## Why
Land a clinical study builder role working in Veeva Vault EDC. I've already built studies in another EDC, so the job is to turn that experience into fluent, credible Vault EDC answers in an interview within the next 2 days.

## Success looks like
- Explain how a Vault EDC study design is structured (Study → Casebook Definition → Event Group → Event → Form → Item Group → Item) and how it becomes a subject's casebook, using Veeva's own terms.
- Map any piece of my previous EDC build experience to the Vault feature that does the same job, and name where the two differ.
- Read and write a basic Vault rule expression (`#define`, `@Form` vs `$` identifiers) and choose the right rule action (query, add event group, derive, and so on).
- Describe the change lifecycle: validate → publish → deploy → new casebook version for amendments, including what counts as a destructive change.
- Answer scenario-style interview questions ("how would you build an oncology cycle?", "how do you handle a mid-study amendment?") without hesitating.

## Constraints
- **2 days** to the target. Prioritise what interviewers ask; skip deep admin and integration topics.
- No access to a Vault EDC environment: learn from Veeva's documentation and simulated exercises only.
- Already experienced in EDC build in another system; don't re-teach CRF design or general clinical data management basics.

## Out of scope (for now)
- Vault CDB (Clinical Database) and Workbench, CDMS API and integrations, Vault Payments, Labs admin, randomization and supply (RTSM) internals.
- Formal Veeva certification prep (Certified Veeva EDC Study Builder is a 5-day course). Revisit after the interview.
