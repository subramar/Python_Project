Must-remember rules of the schedule

  • Only the first Event Group surfaces automatically. Later ones need Add Event Group.
  • A repeating Event Group needs an Add Schedule-type rule for its first sequence. Sites add later sequences manually.
  • Never mark a Log-type Event Group as Repeating (publishing validation error).
  • Sequence references: Cycle[2] for a specific sequence, @EventGroup[-1] / [+1] for the previous/next one (needs an anchor identifier).

Some actions need Veeva Support to enable them, or specific vault settings. See the source.

Processing order after a Form is completed

  1. Set Item Value / Set Derived Value
  2. Dynamic: Add Event Group, Add Event, Add Form
  3. Query

Within each type: derivations → cross-form same-event → cross-form cross-event → all others → Send Email. Disable rules run on save of the controlling Item's Form, outside this order.
