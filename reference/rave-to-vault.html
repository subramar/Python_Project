Key facts

Definition vs executionStudio creates definition records. At casebook creation, Vault copies each one into an execution record per subject (Event Definition → Event).
SurfacingOnly the first Event Group appears automatically. Later ones need an Add Event Group rule. Rules can also add Events and Forms.
Rules can…raise a query · show Event Groups / Events / Forms · enable or disable Items / Item Groups · derive values
Item TypesEDC collected · Status subject status / IDs · Header casebook header · Read-only set by API · Derived set by rule · Reference, Lab for local labs
Reserved namesAvoid Study ID, Country, Site, Subject ID, Event, Event Date, Event Sequence, Form, Form Sequence, Item Group, Item Group Sequence
LifecycleBuild → Validate (CSV of errors/warnings) → Publish (definitions read-only except rules) → deploy → Create New Version for changes
